# Glossary Reference
---


### The Five Realms
1.  **LOCAL:** Filesystems (`posix://`, `win://`).
2.  **NETWORK:** Remote APIs (`http://`, `https://`, `s3://`).
3.  **MEMORY:** In-process buffers (RAM).
4.  **SYNTHETIC:** Procedural generators (Mock data).
5.  **VIRTUAL:** Overlays and logical groupings.
